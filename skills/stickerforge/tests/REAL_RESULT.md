# 실제 폴더 시험 결과

대상은 공냥이 전체 폴더 PNG 166장이다. 원본은 읽기만 했고 수정하지 않았다. 파일명 대신 개수만 적는다.
재현: `python3 run_tests.py --real <폴더>`

## 체크무늬 탐지 (g03)

- 알려진 체크무늬 3장 중 탐지 3장. 탐지율 100%.
- 체크무늬 아닌 163장 중 오탐 0장.
- 세 장 모두 알파 없는 RGB라서 g02도 NO_ALPHA로 같이 잡는다.

## 게이트별 실패 수 (166장 기준)

| 게이트 | 실패 | 내역 |
|---|---|---|
| g01 크기 | 0 | 짧은 변 1000px 이상 전부 통과 |
| g02 알파 | 3 | 알파 없음 3 |
| g03 체크무늬 | 3 | 체크무늬 3 |
| g04 여백(8px) | 69 | 닿음 33, 여백 부족 33, 알파 없음 3 |
| g05 테두리 | 4 | 끊김 1, 알파 없음 3 |
| g06 중복 | 0 | 중복 없음 |

## 해석

- g04 실패 66장(알파 없는 3장 제외)은 기본 여백 8px 기준이다. 기존 qa의 1px 기준보다 엄격하다. 칼선 여유가 필요 없으면 `--margin 2`로 낮춘다.
- g06은 내용 영역만 잘라 256비트로 비교한다. 같은 캐릭터라 8x8 pHash로는 서로 다른 그림이 중복으로 잡혀 비트를 늘렸다.
- g05의 끊김 1장은 눈으로 확인하지 않았다.
