# Original match

Contents: prompt fragment, fits, cautions

## Prompt fragment

Keep the exact drawing style of the reference image: same line weight, same color palette, same shading, same proportions of head, eyes, and body. Draw a new pose only. Do not restyle. Flat sticker art on a transparent background, centered, with a margin around the shape, no frame, no ground shadow, no extra letters.

## Fits well

- Any character the user already has: mascots, illustrations, logos with a face.
- Packs where the brand look matters more than novelty.
- Characters with a distinctive style that a preset would flatten.

## Cautions

- Quality depends on the reference. A low-resolution or cluttered reference gives weak results.
- Name two or three identifying features in the prompt (ear shape, marking, color) to hold the design.
- Never use a generated sticker as the next reference. Use the original image each time.
- If the reference has a background, ask for the character only.
